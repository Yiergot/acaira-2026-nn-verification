\bptitleblock{Mentor question card}{Five questions that work at every stage, and what to add as the week goes on}{DOCUMENT NNV-MQ \quad|\quad REV A \quad|\quad for mentors, clients and stakeholders}
\footnotesize
\begin{multicols}{2}
\subsection*{Always (ask in this order)}
\begin{enumerate}[leftmargin=1.4em,itemsep=2pt]
  \item \textbf{The decision.} Which single decision does your system make that, if wrong, hurts someone? Who?
  \item \textbf{The region.} Over which inputs must it be right \emph{always}? Name them, with units and ranges.
  \item \textbf{The evidence.} What did you test it on — and what does that tell you about the inputs you did not try?
  \item \textbf{The failure.} What would a counterexample look like, who would see it first, and what happens next?
  \item \textbf{The signature.} Who chooses the threshold or the margin, and who signs?
\end{enumerate}

\subsection*{Monday — pitch}
\begin{itemize}
  \item What does a human do today, without your system? That rule is your first specification.
  \item Which responsible-AI principle is this \emph{about} — and how will we see it in the product, not the slides?
  \item Who is the end user you will actually talk to this week?
\end{itemize}

\subsection*{Tuesday — MVP}
\begin{itemize}
  \item Show me one input and one output. Now change one input a little: does the output move the way it should?
  \item Write your first property sentence: ``for every \ldots\ in \ldots, the system must \ldots''.
  \item What is the accuracy claim, and on what?
\end{itemize}

\columnbreak
\subsection*{Wednesday — Alpha}
\begin{itemize}
  \item Fill the worksheet (NNV-WS): the property in English and in pseudo-spec.
  \item Robustness: how much noise in the inputs may change the decision? Who decided that?
  \item Fairness: if a protected attribute is removed, what proxies remain?
  \item What is out of scope for verification here, and what covers it instead (testing, monitoring, a human)?
\end{itemize}

\subsection*{Thursday — Beta}
\begin{itemize}
  \item One table: \emph{tested} (on what) · \emph{monitored} (how) · \emph{verified} (which property) · \emph{governed} (who signs).
  \item Which assumption, if false, breaks the whole argument?
  \item What did a stakeholder object to, and what changed because of it?
\end{itemize}

\subsection*{Friday — final}
\begin{itemize}
  \item The assurance argument in sixty seconds, for a non-specialist.
  \item The honest paragraph: assumptions, limits, what you would do with another month.
  \item What would change your mind about deploying it?
\end{itemize}

\begin{notebox}\footnotesize
\textbf{Saying it back.} ``Your claim is \emph{X}, measured on \emph{Y}. It does not cover \emph{Z} — say so, and say what does.'' \quad ``That is a policy, not a property; who decides it?'' \quad ``Good: that is a counterexample. Now, what changes?''
\end{notebox}

# Participant documents

Print or read on screen; nothing here needs a laptop.

| PDF | What it is |
|---|---|
| `field-guide.pdf` | The whole exercise on paper: vocabulary, toolchain, every command with its real output, design decisions, the fairness stretch, troubleshooting, local install |
| `cheat-sheet.pdf` | Two landscape pages: vocabulary, specification syntax card, command line, how to read results, limits, what a good property looks like |
| `debate-role-cards.pdf` | One page per scenario (medical triage, authentication, autonomous control): facts, four cut-out role cards, decision sheet |
| `debate-protocol.pdf` | A 20-minute facilitator-free protocol for the debate |
| `spec-your-system-worksheet.pdf` | One page to write a property for your own project |
| `reading-list.pdf` | Annotated sources for everything cited |
| `judging-scoresheet.pdf` | For the project panel: eight criteria with tie-breakers |
| `mentor-question-card.pdf` | For mentors: five questions for any stage, plus stage-specific ones from pitch to final demo |
